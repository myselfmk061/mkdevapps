# **App Name**: AppVerse Portfolio

## Core Features:

- App Card Display: Display app cards with app name, logo, short description, and links to app stores.
- Category Grouping: Group applications based on categories defined during application design phase.
- About Me Section: Display an 'About Me' section showcasing the developer's profile and biography.
- Contact Form: Allow users to send messages directly to the developer through a contact form.
- AI-Powered Summary Generator: Generative AI tool creates a brief, engaging summary for each application based on the detailed descriptions.
- AI Category Suggester: Generative AI tool can suggest what category or categories an app may belong to.

## Style Guidelines:

- Background color: Dark blue (#1A2A3A) for a professional, modern look.
- Primary color: Soft light-gray (#D0D3D9) to ensure legibility of app descriptions, contrasting well with the background.
- Accent color: Sky Blue (#72BCD4) for interactive elements like links and buttons.
- Body and headline font: 'Inter', a grotesque-style sans-serif known for its clean and modern appearance.
- Use minimalist, consistent icons to represent different app categories or functionalities.
- Card-based layout with a focus on readability and easy navigation.
- Subtle hover effects on app cards to indicate interactivity.
